NComputing L300 Black Screen lalu Kembali ke Server List: Troubleshooting

12 Februari 2026 ·6 menit baca

Beberapa thin client NComputing L300 di area kerja tiba-tiba menampilkan layar hitam saat user sedang bekerja, lalu beberapa detik kemudian kembali ke daftar server. Setelah user memilih server lagi, kadang bisa masuk, kadang gagal dan mengulang dari awal.

Gejala yang muncul

  • Layar hitam di tengah sesi, tanpa pesan error
  • Kembali ke server list NComputing
  • Kadang berhasil reconnect, kadang gagal berulang
  • Terjadi pada beberapa device sekaligus, bukan satu device saja

Urutan pemeriksaan

1. Cek koneksi jaringan device

Langkah pertama adalah memastikan koneksi LAN di sisi thin client. Saya cek status link di switch, kualitas kabel, dan apakah ada flapping (link up/down). Jaringan yang putus-nyambung adalah penyebab paling umum sesi terputus.

2. Cek beban dan jumlah sesi di server

NComputing L300 bergantung pada server vSpace. Saya periksa apakah jumlah sesi aktif sudah mendekati batas lisensi, dan apakah CPU/RAM server sedang tinggi. Ketika server kelebihan beban, sesi baru bisa ditolak dan klien kembali ke daftar server.

3. Cek konsistensi konfigurasi server

Saya pastikan IP server yang terdaftar di device masih benar dan tidak berubah karena DHCP. Untuk lingkungan produksi, sebaiknya IP server dan device dikonfigurasi statis atau di-reservasi di DHCP.

4. Cek suhu dan daya device

L300 yang kepanasan atau adaptor dayanya mulai lemah bisa reboot sendiri. Saya cek apakah device hangat berlebih, dan apakah adaptor masih mengeluarkan tegangan stabil.

Solusi yang diterapkan

  • Perbaikan kabel dan port switch yang flapping
  • Rebalance sesi di server agar tidak overload
  • Penetapan IP statis/reservasi DHCP untuk server & device
  • Pembersihan dan pengecekan adaptor pada device yang panas

Pelajaran yang saya ambil

Masalah thin client hampir selalu bisa ditelusuri dari tiga hal: jaringan, beban server, dan daya device. Kalau gejala terjadi serentak di banyak device, arahkan curiga ke server atau jaringan dulu — bukan ke device satu per satu.

Catatan ini ditulis secara anonim dan tidak memuat konfigurasi internal maupun data perusahaan.
